Featured Projects

Selected end-to-end builds with live deployments.

Supply Chain Intelligence Platform

Knowledge Graph · RAG · Risk analytics

AI-powered platform that analyzes company relationships, supplier dependencies, and supply-chain risk using a Neo4j knowledge graph (10 companies) and Retrieval-Augmented Generation. Indexes 87,000+ semantic chunks with Sentence Transformers and Qdrant, scores entity risk using degree, betweenness and closeness centrality plus community detection, and serves it through modular FastAPI endpoints and a Streamlit dashboard with an AI assistant.

Neo4j Qdrant NetworkX LangChain FastAPI Streamlit

RAGOps AI

RAG · LLMOps · FastAPI

Agentic document Q&A pipeline using LangChain retrieval chains with tool-calling and conversation memory. ChromaDB + sentence-transformer embeddings, FastAPI + Streamlit, MLflow retrieval tracking, and Docker microservices with GitHub Actions CI/CD, deployed as separate API, UI and MLflow services on Render.

FastAPI LangChain MLflow ChromaDB Docker

Ship CO₂ Emission Predictor

Regression · Pipeline-first

ColumnTransformer + Pipeline architecture for consistent preprocessing. Achieved R² 0.995 and RMSE ~1013. Resolved deployment issues including serialization errors, dependency conflicts, and artifact handling.

scikit-learn Pipelines Hugging Face

Shipment Delay Predictor

Risk prediction · Streamlit

EDA on 10,999 shipments surfaced key delay drivers; engineered logistics-specific features (discount tiers, weight bands, customer escalation signals). XGBoost reached 71.51% F1 and 75.29% AUC‑ROC, delivered in a Streamlit dashboard that gives operations teams instant risk predictions with recommendations.

Python XGBoost Streamlit

Restaurant Demand / Analytics ML Project

Recommenders · Geo analytics

Analyzed 9,551 restaurants across 15+ countries for rating prediction, cuisine classification, and personalized recommendations (TF‑IDF + cosine similarity). Built Folium maps and deployed the full Streamlit app.

TF‑IDF Folium Streamlit
